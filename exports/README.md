# exports/

**Print from [`v2/`](v2/).** That is HOTARU 2.0 — four plates, four MG996R
joints, printed fasteners.

The loose `.stl` files in this directory and the three `hotaru-*.glb` files
are **v1** and are superseded. They describe an earlier machine: SG90 head
servo, six plates, sized for an A1 mini bed, and a set of custom printed
screws that were replaced by M3s because the printed ones would not fit the
rotating base plate.

v1 is kept in the tree for two reasons — the v2 web exporter still shares
code with the v1 one (`cad/export_web.py`), and the project site's older
download links point here. It is not kept because you should print it.
